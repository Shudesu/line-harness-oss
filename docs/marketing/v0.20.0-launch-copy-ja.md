# L Harness v0.20.0 リリース告知セット

正式リリース: https://github.com/Shudesu/line-harness-oss/releases/tag/v0.20.0

## 30秒でわかる今回のアップデート

L Harnessに「Harnessマイル」が加わりました。

友だち追加だけで終わらず、メッセージ送信、リンククリック、フォーム回答、予約、ウェビナー視聴、InstagramからLINEへの帰還など、お客さまの前向きな行動をマイルとして記録できます。

利用者は専用ページで現在のマイル、履歴、登録済みのLINE公式アカウント、次にマイルを獲得できる行動を確認できます。運営者は管理画面で、よく行動している人や長くフォローしてくれている人を横断して把握できます。

## 何ができるようになったのか

### 1. いろいろな行動を、同じマイル残高へまとめられる

対応する行動データがL Harnessへ届くと、共通の台帳へ記録されます。同じ処理が再送されても二重付与されない仕組みになっています。

| 行動 | マイル活用の例 |
| --- | --- |
| LINE公式アカウントを友だち追加 | 初回登録のお礼 |
| 継続フォロー | 7日、30日、90日、180日、365日の継続特典 |
| メッセージ送信 | コミュニティへの継続参加を評価 |
| 計測リンクのクリック | 案内や教材を確認した行動を評価 |
| フォーム回答 | アンケートや課題提出を評価 |
| 予約・イベント予約 | セミナーや個別相談への参加意思を評価 |
| ウェビナー視聴 | 5分、15分、90%視聴完了を段階的に評価 |
| ウェビナーのCTAクリック | 視聴後に次の案内を確認した行動を評価 |
| InstagramのDM・コメント・メンション | IG Harnessから届く反応を評価 |
| InstagramからLINEへ戻る | SNSをまたいだ行動をひとつにつなぐ |
| タグ付与 | セミナー参加、課題完了、会員ランクなどを評価 |
| 購入完了 | 購入イベントに応じた付与 |
| 紹介された人の良質な行動 | 紹介先が視聴・予約・購入まで進んだときに紹介者へ付与 |

### 2. 「紹介人数」ではなく、紹介後の質を評価できる

従来の紹介制度は、友だち追加の人数だけが増えて、実際には行動しない人が集まることがあります。

今回の紹介マイルでは、紹介された人がウェビナーを最後まで見る、予約する、購入するなど、価値のある行動まで進んだときに紹介者へ追加マイルを付与できます。

そのため、単純な人数競争ではなく「本当に合う人を紹介するほど評価される」制度を作れます。

### 3. 複数のLINE公式アカウントをまたいで確認できる

同じ利用者として安全に連携されたデータは、複数のLINE公式アカウントをまたいで残高を集計できます。

利用者向け画面では、現在の実装対象である4アカウントについて「登録済み」「未登録」「マイル反映待ち」「加算済み」を確認できます。未登録のアカウントがある場合は、次の獲得行動として友だち追加を案内できます。

アカウント連携には、署名付き・短時間で失効する専用トークンを使用しています。

### 4. 利用者が自分でマイルを確認できる

従来のASPリンク発行ページを「マイル・紹介」ページへ拡張しました。

- 現在利用できるマイル
- 累計獲得マイル
- 確定待ち、利用済み
- マイル履歴
- 登録済みLINE公式アカウント
- 次にマイルを獲得できる行動
- 参加できる紹介案件とリンク発行

紹介案件を先に表示し、マイル履歴は必要なときだけ開けるアコーディオン形式です。

### 5. 管理画面で熱量の高い人を見つけられる

これまでの「スコアリング」画面を「マイル」画面として活用できます。

- マイル上位の人
- 行動回数が多い人
- 予約、フォーム、リンク、ウェビナーなどの内訳
- 複数アカウントを合算した残高
- 継続フォロー日数
- 再フォロー回数
- ブロック状態
- 紹介によって獲得したマイル

チャットのユーザーサイドバーからも、その人の残高と直近履歴を確認できます。

### 6. 付与処理は非同期で、通常の操作を重くしにくい

利用者の操作時は、まず行動イベントを軽量なキューへ保存します。マイル計算は定期処理で少しずつ行うため、毎秒すべてを再集計する必要はありません。

同じイベントの二重登録を防ぐキー、再試行、失敗記録、付与上限、同じ行動への一度だけの付与なども用意されています。

### 7. ウェビナーと相談予約の自動化も強化

- ウェビナーの行動イベントと視聴導線
- 視聴後のフォローアップ
- Google Calendarの空き時間連携
- Google Meet相談のリマインド

マイルだけでなく、集客から視聴、相談、購入までの流れを追いやすくなりました。

## 初心者向けの活用例

### セミナー運営

1. 友だち追加で5マイル
2. ウェビナーを5分見ると5マイル
3. 15分見ると追加10マイル
4. 90%視聴すると追加30マイル
5. 個別相談を予約すると追加マイル

「登録しただけの人」と「最後まで学んで相談まで進んだ人」を分けて把握できます。

### オンラインコミュニティ

フォームを課題提出に使い、課題提出タグや継続フォロー日数にマイルを設定します。運営者は、発言数だけでは見えない学習継続や提出状況も確認できます。

### 複数のLINE公式アカウントを運営している事業者

商品別、講師別、メディア別にLINE公式アカウントが分かれていても、同じ利用者として連携できればマイルをまとめて確認できます。未登録アカウントは利用者画面から案内できます。

### 紹介キャンペーン

紹介した瞬間に大きな特典を出すのではなく、紹介された人が視聴、予約、購入まで進んだ段階で紹介者を評価します。数だけを増やす紹介よりも、相性のよい人が集まりやすくなります。

### 商品ローンチ

事前アンケート、説明動画、CTAクリック、相談予約、購入を別々の数字で終わらせず、ひとつのマイル履歴として残せます。熱量の高い人へ、適切なタイミングで案内しやすくなります。

## 最初はこの3つから始める

設定を増やしすぎる必要はありません。

1. 友だち追加
2. ウェビナー視聴完了、またはフォーム回答
3. 予約

まずはこの3つだけにマイルを設定し、利用者の反応を見てから対象行動を増やすのがおすすめです。

## よくある質問

### LINE Pointsですか？

違います。HarnessマイルはL Harness上で管理する独自の特典・エンゲージメント記録です。LINEヤフー株式会社が提供するLINE Pointsではありません。

### 現金や暗号資産ですか？

違います。標準状態では現金や暗号資産ではありません。割引や特典へ利用する場合は、各運営者が利用条件、期限、対象商品などを明示して運用してください。

### Instagramのすべての行動が自動で取得されますか？

IG Harnessなどから対応するイベントがL Harnessへ連携された場合に記録できます。外部SNS上のすべての行動を無条件に取得するものではありません。

### Xの反応も自動取得できますか？

v0.20.0の標準機能としてXの自動取得は含まれていません。自己申告や将来の正規API連携を検討する場合も、各プラットフォームの規約に従う必要があります。

### マイルを販売したり、商品割引に使えますか？

台帳には利用・調整を記録できる基盤がありますが、販売や決済時の割引を自動で行う完成済みカート機能として宣伝しないでください。実施する場合は、決済連携、利用規約、失効、返金時の扱いなどを別途設計する必要があります。

## 運用上の注意

- スパム、強制的な反応、規約違反のエンゲージメント獲得には使用しないでください。
- LINE、Instagram、決済サービスなど、接続先の規約に従ってください。
- 何をすると何マイル付くのか、いつ反映されるのか、期限や利用条件を利用者へ明示してください。
- ブロック履歴が存在しない過去データについて、システムが事実ではない履歴を推測することはありません。
- 最初からルールを増やしすぎず、利用者に説明できる少数の行動から始めてください。
