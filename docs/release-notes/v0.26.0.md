# L Harness v0.26.0

リリース準備版（未公開）。対応するX Harnessの最低版は今回のv0.9.0準備ソース（先行分を分割リリースする場合はv0.8.0相当のX-43/45/46/47a実装が必要）。片側だけで有効化しない。

署名付きcapabilities、運営者向けダイジェスト、参加・結果の残数表示、本人が選んだ場合だけのクーポン・次回案内を追加。次回案内は既存broadcastのdraftとして準備し、自動送信・予約はしない。reply tokenがない、または失効した場合に宣伝pushへ切り替えない。クーポンはLIFFで再表示できる。X ID入力は追加しない。

受信者はLINE側 `PUT /api/x-campaign-notifications/:accountId` に `{"friendIds":["管理者のfriend ID"]}` を設定する。所有者・管理者のみ、同じLINEアカウントの最大5人に限定。X側から受信者を指定できない。未設定なら2xx/skipped。

既存migration073とaccount_settings/broadcasts等を利用し、新規DB migrationは不要。X側の021/022は別途適用が必要。設定・運用・検証は `docs/operations/campaign-improvements-20261027.md` を参照。実配信・実OAuth・実機・本番移行は未実施。
