# L Harness v0.24.2

配信の送信元確認と、失敗結果の表示を改善するリリースです。更新には既存の `create-line-harness@0.2.12` と `@line-harness/update-engine@0.0.13` を利用できます。

- 指定した送信元が不明・無効・トークン未設定の場合、既定の送信元で代替せず停止します。
- 即時・予約・キュー・セグメント投入で同じ送信元確認を使います。
- 部分失敗、受付結果不明、LINE受付後の記録保存失敗を「要確認」として表示します。
- 受付済み、または受付結果不明の即時配信を、保存エラーで下書き・予約済みへ戻しません。
- キューの失敗理由と受付人数を保持し、即時送信の失敗応答後も画面の状態を読み直します。

## 更新前に確認すること

登録アカウントのない従来環境では、送信元未指定の配信も環境設定の送信元を使用します。アカウントが登録されている環境では、未指定の送信元を推測しません。既存の下書き・予約・送信中の配信について、送信元と既配信の有無を確認してください。

DBのstatus列は維持しています。成功判定には `lastError` と件数も確認してください。`sent` でも失敗や未確認事項があるものは画面で「要確認」と表示されます。詳しくは[配信安全性の挙動と残る範囲](../BROADCAST-SAFETY.md)を参照してください。

履歴SQLの変更と新しいDBマイグレーションはありません。停止・再開操作やキューの永続的な受信者管理、再試行期限の強化は別途扱います。

## 公開後の更新方法

```sh
npx create-line-harness@0.2.12 update --repo-dir "/path/to/existing/install"
```

更新manifestはschema 2です。独自改修のある環境では、差分を確認してから反映してください。
