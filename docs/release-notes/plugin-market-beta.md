# プラグインマーケットβ版：その数行を、あなたのプラグインに。

公開用原稿。公開日・リリース番号はリリース時に確定してください。

「コードを数行だけ変えたい。でもアップデートするたびに、その変更が消えてしまう」

実際のユーザーから届いたこの声をきっかけに、L Harnessのプラグイン開発と発見の入口を整えました。

新しいプラグインマーケットでは、配信・自動処理・外部連携の拡張と開発リソースを探せます。既存のTypeScript SDKと連携テンプレートに加え、最初の公式プラグイン「条件タグ付け」を用意しました。

独自コードは本体の外へ。本体とは別のGitリポジトリとWorkerで管理し、SDKで本体へ接続します。これにより本体更新によるソースの上書きを避けられます。API互換性の確認は必要なので、SDK固定と更新時の確認手順も公開します。

ひな形は、本体リポジトリで `pnpm plugin:create ../my-plugin` を実行すると作成できます。数行の条件変更から始めて、自分の運用に合った拡張へ育ててください。

β版は導入ガイド付きのカタログとして始めます。各プラグインは別途セットアップする方式です。管理画面内でのワンクリック導入、決済、管理画面の表示差し替えは含まれません。

そして、最初の作り手を募集します。自分のために書いた数行が、同じ課題を持つ誰かの助けになる。その小さな拡張が集まる場所を、ここから作っていきます。

- [開発ガイド](https://github.com/Shudesu/line-harness-oss/blob/main/docs/plugins/README.md)
- [掲載申請](https://github.com/Shudesu/line-harness-oss/issues/new?template=plugin-submission.yml)

## 公開前の作業

- OSSへコード・ドキュメント・Issueテンプレートを同期し、上記のURLが公開されていることを確認する。
- OSSのREADMEは同期対象外のため、開発ガイドと公式プラグインの紹介リンクを個別に追記する。ひな形作成コマンドは同期対象の `examples/plugins/create-plugin.mjs` に配置済み。掲載申請テンプレートは今回追加したファイルだけを同期する。
- テスト用の本体へ接続し、確認モード・タグ付与・再実行・停止を検証する。SDKと本体の組合せを記録する。
- 管理画面のリリースと同時に本原稿をリリースノートへ掲載する。
