# L Harness v0.26.1

公開日: 2026-11-01（JST）。

## LIFF SDKのセキュリティ更新

LIFFアプリに同梱する `@line/liff` を2.28.0から2.31.2へ更新し、依存関係の下限も2.31.2へ引き上げました。[LINE公式のお知らせ](https://developers.line.biz/ja/news/2026/10/20/liff-sdk-issue/)に対応する更新です。

リダイレクトURL内の `?` と `%3F` を保持する回帰テストを追加しました。ソースを取得しただけでは稼働中のLIFFアプリは更新されないため、インストール済み環境では更新・再ビルド・配布まで行ってください。

## その他の修正

公開mainに取り込み済みの、1人分のマイル残高取得でプログラム全体の履歴を走査しない修正（#415）を含みます。

## 更新時の注意

v0.26.0からの新規DB migration・必須シークレットの追加はありません。以前の版から更新する場合は、間の各リリースの移行条件も確認してください。v0.25.0以降のXキャンペーン連携の条件は引き続き適用されます。

公開リリースの配布物はCIでテスト・型チェック・ビルドを行います。実際のLINEアプリ上でのログイン・送信操作は、このOSSリリース検証には含みません。
