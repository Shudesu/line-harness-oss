# L Harness v0.25.0

状態: リリース準備中。現在の公開版はv0.24.3です。

LINE先行のXキャンペーン参加を追加します。X IDを入力せず、LINEで本人確認して個人用合言葉を受け取り、投稿の照合後に特典を受け取れます。既存友だちはLIFF表示で初期pushを省きます。

HMACイベント、アカウント固定、タグ・シナリオ実行、通知の再送と重複防止に対応します。結果確認のreplyと自動pushが同時に動く場合も、一つの自動配布経路を選びます。reply履歴は自動応答として記録します。旧X ID自己申告フォームの送信は停止し、新参加画面または移行案内を表示します。

対応するX Harness v0.7.0、追加migration、共有キーが必要です。厳格ティアにはTurnstile設定も必要です。[導入・移行・復旧手順](../operations/line-first-x-gates.md)を参照してください。PRのmigrationは`NNN`の仮番号で、マージ時に採番してbootstrapを再生成します。

単体テスト、両repoのHTTP契約、bootstrap整合、型チェック・ビルドを合成データで確認します。実iOS/Android、実OAuth・Turnstile、実メッセージ配信、本番移行は未検証です。タグ公開・本番配信・npm公開はこの変更だけで実行しません。

## 依存ライブラリの更新

既存依存の監査警告に対応し、Next 15.5.28、Hono 4.13.14以降、MCP SDK 1.32以降、React Router 7.18.2以降と修正版の間接依存を使用します。Zodは4へ移行し、レコードのキー型を明示しました。sharpは0.35.5以降です。Node.jsは20.9以上が必要で、今回の検証は22.22.2です。npmパッケージの公開は別操作です。

`pnpm audit --prod`は既知の警告0件です。これは未知の脆弱性や全経路の安全を保証するものではありません。[検証記録](../operations/line-first-validation.md)を参照してください。
