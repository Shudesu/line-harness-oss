# L Harness Plugin Market

**その数行を、あなたのプラグインに。**

プラグインマーケットβ版は、配信・自動処理・外部サービス連携の拡張と開発リソースを探せるカタログです。管理画面の「プラグインマーケット」から導入ガイド・ソースへ進めます。

## すぐ試す

本体リポジトリを取得して、ルートで次を実行します。新しいフォルダは本体の**外**に作られます。

```bash
pnpm plugin:create ../my-plugin
cd ../my-plugin
npm install
npm run typecheck
npm run build
git init
```

最初のプラグインは[条件タグ付け](../../examples/plugins/tag-rules/README.md)。初期状態は確認モードで、定期実行も無効です。`src/rules.ts` の条件を数行変えることで、運用に合わせたタグ付けを作れます。

外部サービスをつなぐ場合は既存の[連携テンプレート](../../packages/plugin-template/README.md)から始められます。

```bash
pnpm plugin:create ../my-integration integration
```

こちらは開発用のコード例です。外部APIクライアント・Webhookの署名検証・通知の重複防止を実装してから利用します。

## 本体の更新から守る構成

```text
L Harness 本体（公式アップデートの対象）
    ↑ SDK / HTTP API
独立したプラグイン（自分のGitリポジトリ・Worker・設定・DB）
    ↑ 定期処理や外部サービスのイベント
```

本体に直接書いた独自変更は、公式バンドルの更新で置き換わる可能性があります。処理を別リポジトリ・別Workerへ移し、SDK経由で呼び出すことで、独自ソースの上書きを避けます。コードが残ることとAPI互換性が続くことは別なので、更新前の接続確認は必要です。

| 作りたいもの | 拡張方法 |
| --- | --- |
| 来店・契約状態に応じた分類 | 友だち情報を読み、SDKでタグを追加 |
| 独自の配信ルール | タグを起点にシナリオ配信、またはSDKから配信を操作 |
| 予約・顧客管理サービス連携 | 外部API / 署名検証済みWebhookからSDKを呼ぶ |
| AIによる運用 | 既存のMCP Serverや、連携テンプレートのMCPツール |
| 管理画面の表示差し替え | 現時点の拡張対象外。UI用の拡張ポイントは未実装 |

API URLは**自分のL Harness本体**を指定し、LINE送信を `api.line.me` へ直接実装しません。本体が送信とログを管理します。独自DBはプラグイン側に持ち、本体のD1のスキーマを変更しないでください。

## 開発・リリースの約束

1. SDKのバージョンとロックファイルを固定する。生成コマンドはnpmに存在する `@line-harness/sdk@0.24.0` を使用します。
2. READMEに接続設定・使用API・必要な権限・外部送信する情報・停止方法を記載する。カタログの権限説明はAPI側の強制的な権限制限ではありません。
3. キーはWorkerのsecretや環境変数で管理する。ブラウザや配布するソースに入れない。
4. 通知はイベント単位の重複防止、再送、失敗時の扱いを決める。担当者の手動返信は本体の送信元ルールに従う。
5. 本体・SDKの動作確認バージョンを記録する。非互換変更は自分のプラグインの変更履歴へ記載する。
6. 自分のWorkerだけを更新・停止する。本体の更新コマンドや本体用Worker名を流用しない。

## マーケットに掲載する

[掲載申請フォーム](https://github.com/Shudesu/line-harness-oss/issues/new?template=plugin-submission.yml)から、ソースURL・導入手順・ライセンス・動作確認したバージョン・利用データを記載して申請します。申請は公開Issueになるので、APIキーや顧客データは記載しないでください。

掲載は申請後の確認を経てカタログへ追加します。カタログは `apps/web/src/lib/plugin-catalog.ts` で管理し、本体のリリースに同梱します。第三者製の拡張を自動実行する仕組みはありません。

β版は個別セットアップ方式です。ワンクリック導入・課金・自動更新・第三者プラグインの実行隔離は含まれません。公式の稼働プラグイン、開発用テンプレート、SDK、MCPを区別して掲載します。
