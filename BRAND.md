# L Harness brand policy

## Product name

The public product name is **L Harness** from 2026-08-19. It is an independent,
self-hosted CRM that integrates with the LINE Official Account APIs.

## Compatibility identifiers

Existing technical identifiers remain unchanged to avoid breaking users:

- Repository: `Shudesu/line-harness-oss`
- CLI: `create-line-harness`
- npm scope: `@line-harness/*`
- Paths, environment variables, database names, and API identifiers using
  `line-harness`

These strings identify software interfaces; they are not the public product
display name.
